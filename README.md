# Minimalist Photography Gallery (Demo)

A clean, modern, minimalist personal photography gallery web application designed with a 2-layer experience, auto-slider, responsive masonry grid layout, and fullscreen lightbox photo viewer.

> **Note:** This repository is currently a **Demo** release. Further updates, features, and refinements will be added in future iterations.

## Features

- **Layer 1 (Landing Page):** Auto-rotating featured photo slider, clean minimalist header, and quick explore trigger.
- **Layer 2 (Gallery Grid):** Responsive masonry grid layout supporting portrait & landscape orientations cleanly.
- **Fullscreen Lightbox:** Clean modal image viewer upon clicking any photograph.
- **Minimalist Aesthetic:** High-end studio aesthetic with clean typography and spacing.

## File Structure

- `index.html` - HTML5 structure for Layer 1, Layer 2, and Lightbox.
- `style.css` - Custom styles, typography, auto slider, and responsive masonry layout.
- `script.js` - Navigation logic, layer switcher, and lightbox controls.
- `images/` - High-resolution photograph assets.

## Getting Started

No build tools or dependencies required. Simply open `index.html` in any modern browser.

```bash
# Clone the repository
git clone https://github.com/raydinata/Gallery.git

# Open the gallery
cd Gallery
start index.html
```
